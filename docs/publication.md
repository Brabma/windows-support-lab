# GitHub publikace

Cílový účet potvrzen uživatelem: Brabma. Samostatný veřejný repozitář [windows-support-lab](https://github.com/Brabma/windows-support-lab) byl vytvořen 13. 10. 2026. Funkční základ a vybrané důkazy byly zveřejněné 14. 10. 2026. Projekt dále rozvíjí scénář kanceláře, provozní postupy, diagnostický skript a dva opravené incidenty; další etapy jsou výslovně označené jako plán.

Veřejný balíček tvoří pouze README.md, .gitignore, docs/*.md, operations/*.md, incidents/*.md, scripts/*.ps1 a jednotlivě zkontrolované vybrané důkazy. Při exportu použít přesný seznam konkrétních souborů; nikdy kopii celého pracovního adresáře. `.gitignore` je doplňková ochrana, ne náhrada revize.

Nepublikovat private, ISO, VDI, VirtualBox konfigurace, tokeny, hesla, syrové logy, osobní e-maily ani licenční identifikátory. Licence projektu zatím není určena autorem; nevkládáme automaticky MIT či jinou licenci.

Dokumentace smí být zveřejněná už jako příprava s jasným stavem. Dokončené incidenty přibudou až po provedení. Veřejné README nemá tvrdit, že lab funguje, jen protože existují profily VM nebo návod.
